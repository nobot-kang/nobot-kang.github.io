재건축 분담금 계산기: 기준안과 변경안을 나란히 비교하기

일반분양 등 외부 수입과 조합원 분양 수입, 사업비·평가액·개인 가격을 나누어 입력합니다. 가상 기준안과 변경안의 비례율·권리가액·분담금 차이를 비교하는 계산기입니다.

재건축 분담금 계산기에서 조합원 분양가만 낮추면 내 부담도 그대로 줄어들까요? 전체 조합원 분양 수입을 함께 바꿨는지에 따라 결과가 달라집니다. 이 도구는 외부 수입·조합원 수입·사업비와 개인 금액을 나누어 기준안과 변경안을 비교합니다. 기본값은 모두 가상 예시이며 실제 조합의 평가액이나 예상 사업비가 아닙니다.

같은 기준으로 전체 금액과 개인 금액을 맞춥니다

기본 가상 사업장의 개인 분담금은 3억 원입니다. 외부 수입만 10% 낮추면 3.6억 원이 되지만, 모든 조합원의 분양가를 10% 낮추어 전체 수입과 개인 가격을 함께 바꾸면 3억 원으로 유지됩니다. 아래에서 두 조건을 직접 비교할 수 있습니다.

  1. 두 안의 분담금 계산
  2. 예시 결과와 산식
  3. 한 사람의 가격과 전체 가격
  4. 음수·작은 차이의 뜻
  5. 실제 안내문과 대조할 순서

어떤 입력을 바꾸어 비교하나요?

먼저 기준안의 여섯 금액을 확인한 뒤 변경안에서 비교하려는 금액을 바꾸세요. ‘일반분양 등 외부 수입’에는 조합원이 아닌 곳에서 들어오는 수입을, ‘조합원 분양 수입 합계’에는 조합원이 선택한 분양가의 합계를 넣습니다. 이 합계는 조합원이 실제로 납부할 분담금 합계와 다릅니다.

개인 평가액은 종전자산 총액에, 개인 선택 분양가는 조합원 분양 수입 합계에 포함되어야 합니다. 평가액·권리가액·분담금의 뜻을 먼저 확인하면 서로 다른 금액을 넣는 실수를 줄일 수 있습니다. 금액을 수정한 뒤 두 안 비교하기를 누르세요.

두 안 모두 가상 입력입니다. 금액 단위는 억 원이며 쉼표 없이 최대 소수 네 자리까지 입력합니다. 0.0001억 원은 1만 원입니다. 전체 사업 금액은 0~1,000,000억 원, 개인 금액은 0~1,000억 원이 도구의 입력 범위이며 시장·법적 한도가 아닙니다.

좁은 화면에서는 표를 좌우로 움직여 두 안을 확인할 수 있습니다. 표에 초점을 둔 뒤 방향키로도 이동할 수 있습니다.

전체 조합원 차액 합계는 총사업비에서 외부 수입을 뺀 값입니다. 모든 사람의 가격과 평가액이 같은 범위로 합산된 단순 회계를 가정합니다. 개인 분담금에 인원수를 곱한 값이 아닙니다.

중간 계산은 반올림하지 않았습니다. 만 원 미만의 금액·증감은 그 크기와 부호를 따로 표시합니다. 표시 금액이 같아도 반올림 전 차이는 있을 수 있습니다. 실제 정산·환급·대출 승인·납부 일정은 이 계산으로 정하지 않습니다.

기본 가상 예시는 어떻게 계산하나요?

기준안은 외부 수입 6,000억 원, 조합원 분양 수입 9,000억 원, 총사업비 9,000억 원, 종전자산 총액 6,000억 원입니다. 개인 평가액은 6억 원, 선택 분양가는 9억 원입니다. 같은 조건의 조합원 1,000명이라고 두면 개인 금액과 전체 합계가 맞습니다.

  1. 총수입: 외부 수입 6,000억 원+조합원 분양 수입 9,000억 원=15,000억 원입니다.
  2. 비례율: (총수입 15,000억 원−총사업비 9,000억 원)÷종전자산 총액 6,000억 원=100%입니다.
  3. 개인 권리가액: 개인 평가액 6억 원×100%=6억 원입니다.
  4. 개인 분담금: 선택 분양가 9억 원−권리가액 6억 원=3억 원입니다.

이는 서울시가 설명하는 비례율·분담금 산식을 가상 금액에 적용한 것입니다. 각 예시 버튼은 기준안을 이 출발점으로 되돌린 뒤 변경안의 해당 항목을 바꿉니다. 예시를 불러오면 이전에 편집한 금액도 바뀝니다.

각 조건은 따로 적용합니다. 외부 수입 감소 예시는 6,000→5,400억 원, 조합원 가격 감소 예시는 수입 합계 9,000→8,100억 원과 개인 가격 9→8.1억 원을 함께 바꿉니다. 사업비 증가 예시는 비용 9,000→9,200억 원입니다. 표의 비례율은 소수 둘째 자리로 반올림했으며 계산에는 반올림 전 값을 사용했습니다. 좁은 화면에서는 표를 좌우로 움직이거나 표에 초점을 둔 뒤 방향키를 사용할 수 있습니다.

전체 조합원 차액 합계도 같이 확인합니다. 이 단순 회계에서 모든 조합원의 분담금을 합하면 총사업비에서 외부 수입을 뺀 값과 같습니다. 기준안은 9,000−6,000=3,000억 원입니다. 개인의 평가액과 선택 가격이 다르면 이 합계를 인원수로 나눈 값이 내 분담금은 아닙니다.

내 선택 가격만 바꿀 때도 전체 수입을 바꾸나요?

선택 가격의 변경이 조합원 분양 수입 합계에 반영되는 가정이라면 그 차이만큼 함께 바꿔야 합니다. 한 사람만 다른 주택을 선택하는 경우와 모든 조합원의 가격을 같은 비율로 낮추는 경우를 구분하세요.

기본 가상 사업장에서 한 사람의 가격만 9억 원에서 8.1억 원으로 바꾼다면 전체 조합원 분양 수입은 9,000억 원에서 8,999.1억 원으로 줄어듭니다. 다른 입력을 그대로 두면 그 사람의 권리가액은 5.9991억 원, 분담금은 2.1009억 원입니다. 같은 평가액을 가진 다른 사람들의 권리가액도 소폭 달라집니다.

반면 ‘조합원 가격 모두 10% 감소 예시’는 전체 수입을 8,100억 원으로 낮춥니다. 권리가액이 5.1억 원이 되어 분담금은 8.1−5.1=3억 원입니다. 개인 가격은 두 경우 모두 8.1억 원이지만 전체 수입 가정이 달라 결과도 다릅니다. 자세한 설명은 일반분양 수입과 조합원 분양가의 차이에서 이어집니다.

선택 주택 구성이 바뀌면 실제 사업비나 외부 분양 물량도 달라질 수 있습니다. 이 도구는 입력한 조건의 산술을 비교하므로, 한 항목만 바꾼 계산과 사업계획 전체를 다시 만든 전망을 구분해야 합니다.

분담금이 음수이거나 두 결과가 거의 같으면 어떻게 읽나요?

음수 분담금은 이 산식에서 권리가액이 선택 분양가보다 크다는 뜻입니다. 지급받을 환급액이나 지급 날짜가 확정되었다는 뜻은 아닙니다. 총수입보다 사업비가 큰 입력에서는 비례율과 권리가액도 음수로 계산되며, 결과에 해당 조건을 따로 표시합니다.

종전자산 총액이 0이면 나눗셈을 할 수 없어 계산을 멈춥니다. 개인 평가액이나 분양가가 각각의 전체 합계보다 커도 먼저 입력을 확인하도록 안내합니다. 이런 기본 관계를 통과했다고 실제 사업비·평가액·사업 가능성까지 검증된 것은 아닙니다.

입력은 만 원 단위까지 받지만 비례율을 곱한 결과는 만 원보다 작은 차이를 만들 수 있습니다. 중간 값을 반올림하지 않고 최종 금액만 만 원 단위로 표시합니다. 만 원 미만의 금액과 증감은 따로 안내하며, 산식상 정확히 같은 경우에만 ‘같습니다’라고 표시합니다. 눈에 보이는 두 분담금이 같더라도 작은 증감이 남을 수 있습니다.

계산 결과를 실제 사업 안내문과 어떻게 대조하나요?

  1. 범위와 날짜: 수입·비용·평가액이 같은 계획의 같은 범위인지 확인합니다. 상가·현금청산·보조금·별도 정산을 포함한 방식이 다르면 먼저 범위를 맞춥니다.
  2. 변경 대상을 명시: 일반분양 가격·물량, 전체 조합원 가격, 내 선택 가격 중 무엇을 바꿨는지 적습니다. 총수입을 고정한 채 개인 가격만 바꾸는 가정이 맞는지 확인합니다.
  3. 비용 중복: 사업 지연의 추가 이자가 이미 사업비에 포함되어 있는지 확인합니다. 같은 개인 이자를 사업비와 별도 지출에 두 번 더하지 않습니다.
  4. 현금의 날짜: 분담금 총액, 이미 낸 금액, 앞으로 낼 금액과 날짜를 나눕니다. 대출 원금 상환·세금·선택품목·임시거처 자금까지 이 계산기가 자동으로 채우지는 않습니다.

계산 결과를 볼 때는 결과 숫자와 함께 두 안에서 바꾼 입력을 확인하세요. 비례율이 높아졌어도 개인 가격과 평가액이 함께 바뀌면 부담이 줄지 않을 수 있습니다. 입력한 전체 금액과 개인 금액의 관계를 설명할 수 있어야 비교 결과도 해석할 수 있습니다.

공식 산식·가상 입력·계산과 표시 방법

서울시 정비사업 정보몽땅의 비례율·분담금 안내를 2026년 10월 19일 확인했습니다. 비례율 기초 글과 같은 산식을 사용합니다. 모든 기본 금액과 예시 변화율은 가상이며 실제 거래·허가·공사비 지수로 보정하지 않았습니다. 실제 조합원 자격·평가·세금·대출 승인·정산이나 환급 시기를 판정하지 않습니다.

입력은 억 원 단위에서 소수 네 자리까지 읽고 중간 비례율·금액·차이는 반올림하지 않습니다. 최종 금액은 만 원 단위, 비례율은 소수 둘째 자리로 반올림합니다. 정확히 절반인 값은 절댓값이 커지는 쪽으로 표시합니다. 만 원 미만의 금액과 매우 작은 비례율은 0과 구분해 크기·부호를 표시합니다.

기준·수입·비용 변화와 임의의 가상 조건을 별도의 계산으로 대조했습니다. 0 분모, 허용 범위를 벗어난 값, 개인·전체 합계의 불일치, 음수 결과, 작은 차이와 초기화를 확인했습니다. 전체 조합원 차액 합계는 모든 사람의 분양가·평가액 합계가 입력한 전체 금액과 맞는 단순 회계의 항등식입니다. 개인 한 명의 결과를 전체 사람에게 동일하게 적용하지 않습니다.
