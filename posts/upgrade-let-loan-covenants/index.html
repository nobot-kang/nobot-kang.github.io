기존 집을 임대하기 전: 대출·거주 약정에서 멈출 조건

기존 집 임대·추가 매수 계획을 처분·추가주택 구입금지·전입·거주·만기 조건에 대조합니다. 미확인 대출을 빼고 매수 재원 부족을 따로 확인합니다.

파파펭귄 · Nobot Kang작성 2026-10-24

분석 기간 · 가상 보유·반환 장부 · 실제 승인 아님　|　자료 기준일 · 2026-10-23

기존 집을 임대하면 보증금이 들어오고, 그 돈에 새 대출을 더하면 다음 집을 살 수 있을 것 같습니다. 그런데 현재 대출에 기존 집 처분이나 추가 주택 구입금지 약정이 남아 있다면 금액을 더하기 전에 계획부터 다시 확인해야 합니다. 무엇을 확인하고 어디에서 계산을 멈춰야 할까요?

가상 예시에서 보증금 수취와 기존 대출 상환 뒤 현금은 4억 원입니다. 새집과 비용에 필요한 9억 8,200만 원까지는 5억 8,200만 원이 부족합니다. 제안된 새 대출이 미확인 상태이거나 제한과 충돌하면 이 금액을 입금으로 넣어 매수를 완료 처리할 수 없습니다.
이 글의 순서
  1. 어떤 약정부터 보나요?
  2. 같은 주담대에도 조건이 같나요?
  3. 미확인 대출을 빼면 얼마가 부족한가요?
  4. 확인 결과를 어떻게 남기나요?

기존 집 임대 계획과 어떤 약정이 충돌하나요?

계약서의 대출 종류·담보·약정 대상과 실제 계획을 한 줄씩 대조합니다. 금융위원회의 2026년 6월 15일 안내는 기존 주택 처분, 추가주택 구입금지, 전입 약정 유형을 설명합니다. 이 중 어떤 약정이 내 대출에 있는지 확인하기 전에는 ‘임대하면 된다’고 결론 내릴 수 없습니다.

세목별 보유·거주 요건대출 조건을 세금에도 대입세목을 나눠 확인 · 취득·양도·과세기준일과 유보금 확인

가령 처분 약정이 있는 집을 계속 소유하면서 임대하려는 계획은 처분 조건과 충돌합니다. 다른 집을 추가 취득하지 않기로 한 약정이 있다면 새집 취득도 먼저 확인할 대상입니다. 약정 대상이 차주인지 세대인지, 언제까지 무엇을 해야 하는지는 실제 서류로 남겨야 합니다.

같은 주택담보대출이면 적용 조건도 같은가요?

상품과 신청·실행 시점, 주택 소재지, 기존 보유, 자금 목적을 나눠야 합니다. 2025년 6월 27일 금융위 방안은 수도권·규제지역에서 기존 집을 처분하지 않는 추가 구입 목적 주담대 제한과 처분 조건부 경로를 구분했습니다. 2026년 6월 30일 발표도 수도권 다주택 구입 제한을 설명합니다. 예전 발표의 대출 비율이나 경과 조건을 오늘의 새 신청에 그대로 옮기지 않습니다.

HF 디딤돌 FAQ는 2025년 3월 24일 이후 신청분의 실거주 기간과 2024년 6월 19일 이후 신청분의 1주택 유지 의무를 각각 설명합니다. 특정 상품·신청분의 설명을 모든 주담대에 적용하지 않습니다. 2026년도 가계부채 FAQ의 일부 만기연장 예외도 재심사·증빙 조건과 함께 읽어야 합니다.

확인한 다섯 공식 문서는 약정 유형과 적용 조건을 대조하는 출발점입니다. 현재 모든 대출·예외·개인 계약의 적용 결과를 자동 판정하는 목록은 아닙니다. 특히 ‘기존 집을 남기고 새 대출 6억 원으로 수도권 집을 추가 매수한다’는 아래 안을 실행 가능한 전략으로 승인하지 않습니다.

새 대출을 확인하지 못하면 매수 장부는 어디에서 멈추나요?

현재 집 8억 원·기존 부채 2억 원·현금 1억 원에서 출발합니다. 임대 조건이 별도로 확인돼 보증금 5억 원을 받고 기존 부채 2억 원을 정리했다고 놓으면 현금 4억 원이 남습니다. 임대보증금 반환채무 5억 원도 함께 생깁니다. 다음 집 9억 5,000만 원과 가상 취득·이사 비용 3,200만 원에는 9억 8,200만 원이 필요합니다.

계획 대출 6억 원은 대출 승인이나 실행 입금이 아닙니다. 미확인·제한 충돌·산술 비교의 세 상태에서는 확인된 대출 입금이 없으므로 부족은 모두 5억 8,200만 원입니다. 새집 자산과 새 대출 채무도 아직 기장하지 않습니다. 보증금 수취와 기존 상환 역시 실제 계약이 확인되었다는 뜻이 아니라 앞 단계만 따로 둔 가정입니다.

충돌이 확인됐다면 해당 조달을 빼고 계획을 다시 세워야 합니다. 미확인이라면 확인 전 계약 이행 재원으로 쓰지 않습니다. 금융회사의 실제 심사·약정·실행일과 세금 유보금을 확인한 뒤에야 다음 지급표로 넘어갈 수 있습니다.

서류에는 어떤 순서로 확인 결과를 남기나요?

  1. 현재 보유 대출별 상품·담보·신청/실행일·남은 원금·추가약정을 모읍니다.
  2. 임대 시작·추가 취득·전입·기존 집 처분·보증금 반환의 예정일을 같은 달력에 놓습니다.
  3. 계획과 충돌하는 조항, 아직 확인하지 못한 조항, 확인한 증빙을 나눠 적습니다.
  4. 새 대출은 실제 금액·실행 조건·만기 통지를 받은 뒤 재원에 넣습니다. 세금은 세목별 일시적 2주택 요건과 따로 대조합니다.

약정 확인은 금리 비교보다 먼저 할 일입니다. 보유·임대 계획이 조건과 맞는지와 실제 지급에 쓸 돈이 있는지를 모두 확인해야 합니다.

공식 자료의 시점과 가상 계산 범위

공식 자료는 2026년 10월 23일 확인했습니다. 위 금융위 네 문서의 게시일·적용 범위와 HF FAQ의 상품·신청일별 구분만 사용했습니다. 페이지 게시일이 없는 FAQ에 임의의 발표일을 붙이지 않았으며 과거 안내를 현재 개인 대출의 확정 조건으로 대체하지 않았습니다.

금액은 모두 가상이며 보유 주택·기존/새 대출·받은 보증금 채무·낸 보증금 채권을 구분했습니다. 실제 임대 허용·추가 차입·세액·계약 이행 가능성은 계산하지 않았습니다. 새 차입이 확인되지 않은 상태의 부족액과 실행을 가정한 산술을 분리해 독립 대조했습니다. 금액은 마지막에 만원 단위 소수 첫째 자리까지 반올림했습니다.
